K Dimensional Tree

A k-d tree divides space repeatedly in order to speed up nearest neighbor search, K nearest neighbors search, and range searches (= all points in a K dimensional box, or a radius).

To illustrate, there are 8 points to the right. Those are split into two groups of four points by the black line. Those are split into groups of two points by the red and yellow lines. Finally, the gray, yellow, green, and purple line split those to single points.

This is represented as a tree like this - the first split is at the root, the next two splits are it's children, etc.

This implementation divides space in repeating order on the x, y, and then y axis, similar to the illustration above. There are alternatives, such as splitting along the axis with the widest distribution of points. In this case, a tree with points being the stars in the galaxy wouldn't be split along the height of the galaxy as often as along its height and width.

Using a tree quickly narrows down the set of points the code needs to look at, which is why it is faster than scanning all the points in a large set. On the other hand, it is a textbook example of pointer chasing, which leads to cache misses, branch mispredictions, and serialization (go down the tree node by node). This is ameliorated by having leaf nodes hold a group of points in a contiguous container, and iterating over the container to look for a nearest neighbor, etc.

This requires striking a balance between two evils - brute force searches in contiguous containers, and pointer chasing in the tree. For my laptop and test cases, a leaf of ~100 points works fastest. Your mileage may vary based on DRAM performance & timing parameters, tree size, queries, etc.

K-D Tree API

Constructors: default (empty tree), move, and from an array of K-D points (read: std::array of K floats).

insert: clears a tree, and inserts an array of K-D points.

pointsInBox: accepts a K-D box (two arrays, one of min axis values, another of max), and returns all the points in the tree within the box.

nearestNeighbor: accepts a point, and returns the closes point to it in the tree.

KNearestNeighbors: accepts a point, and returns the K closest points to it in the tree.

boundingBox: returns the K-D tree's bounding box.

nodeCount: returns the number of nodes in the tree.

getNumPoints: returns the number of points in the tree.

TreeHeight: returns the tree's height.

PrintTree: prints the tree.
